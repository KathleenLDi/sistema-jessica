# Espaço Jéssica Carneiro — Protótipo Personalizado

Protótipo navegável personalizado com a identidade visual do Espaço Jéssica Carneiro, em HTML, CSS e JavaScript puro.

## Como abrir

1. Extraia o ZIP.
2. Dê dois cliques em `index.html`.
3. O sistema abrirá no navegador.

Não é necessário instalar Node.js, banco de dados ou servidor.

## Login do protótipo

Use qualquer e-mail/usuário e senha preenchidos. Já deixamos valores de demonstração preenchidos.

## Funcionalidades simuladas

- Login da proprietária.
- Dashboard financeiro.
- Agenda semanal.
- Bloqueio de conflito de horários considerando a duração do serviço.
- Cadastro de clientes.
- Cadastro de serviços.
- Cadastro e movimentação de estoque.
- Alerta de estoque baixo.
- Entradas e saídas financeiras.
- Controle de boletos e status de pagamento.
- Alertas de boletos vencidos/próximos.
- Botão de WhatsApp com mensagem pronta.
- Dados armazenados no `localStorage` do navegador.

## Observação

Este é um protótipo de interface. Não possui segurança real nem backend. Para produção, deve ser conectado a uma API, banco de dados e autenticação segura.
